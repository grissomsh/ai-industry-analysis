# AI 产业分析：GPU/算力产业链梳理 + 市场观点核验

## 项目定位

两条相互支撑的研究线：

1. **产业链梳理**（01-04）：GPU 整条产业链上下游的软硬件公司（上市 + 未上市），重点标注国产替代率较低的环节，形成「环节 → 产品 → 公司 → 上市状态 → 国产化率」的结构化清单与替代率地图。
2. **市场观点核验与前瞻**（05-07）：对市场热点观点进行数据驱动的真伪判定与分层结论，并延伸至前瞻情景推演；方法论沉淀为 `market-view-verify` skill，可复用于任何市场论断。

## 研究线一：产业链梳理

1. **分层**：按通行研报口径切分 L0 上游制造根基 → L1 芯片与软件栈 → L2 整机与基础设施 → L3 应用需求方，共 4 层 6 段 30+ 细分赛道。
2. **映射公司**：每个赛道填「海外主导者 / 上市公司（含代码）/ 未上市公司（含资本进度）」。
3. **打标**：国产化率（约值 + 证据等级）、卡脖子等级（★1~5）、AI 收入占比/供应链风险/海外产能。
4. **消化一手材料**：招股书/年报提取研发投入、募投结构、收入质量（扣非口径），来源分级标注。

## 研究线二：市场观点核验与前瞻

五步流程：**论据提取并编号 → 数据脚本核验（FRED 宏观面板 + 腾讯/新浪行情快照）→ 检索补证（含反方证据）→ 论证层评估 → 性质/时点分层结论**。

关键纪律：

- 事实核验、论证评估、结论判定三层分离，不因论据属实接受结论，不因结论激进否定论据。
- 观点判定采用**性质之变 / 时点之变**分离表：结构性变化看融资结构、定价范式、约束条件；时点判断看四大终结信号（信用利差、VIX、技术破位、龙头指引下修）。
- 前瞻判断一律附**主观概率与失效条件**，到期核验。

## 证据与数据规范

- **证据分级**：A = 官方一手数据（FRED/BLS/交易所/公司公告/招股书原文）；B = 机构转述、媒体汇总（标注待复核）；C = 传闻级/未核验。
- **引用著录**：来源客观标注机构、日期、数据口径与证据等级。
- **盈利质量口径**：净利润一律剔除政府补助、公允价值变动、股权浮盈后评估（摩尔线程 Q1 补贴、天数智芯浮盈案例已验证该口径的必要性）。
- **数据主表**：`data/companies.csv` 为唯一事实源，文档与 CSV 不一致时以 CSV 为准。

## 维护约定

- 产业链清单：季报后更新公司数据与状态；替代率分级变动需 A 级证据支撑。
- 观点核验：同一主题后续验证以「第 N 轮」追加或更新原文，保留判断演化轨迹。
- 宏观面板：`scripts/fetch_fred.py` 按需刷新（FRED 滞后 2-4 个交易日，最新行情以新浪快照补齐）。

# AI 产业梳理 — 起步专题：GPU/算力产业链

## 目标

梳理 GPU 整条产业链上下游的软硬件公司（**上市 + 未上市**），重点标注**国产替代率低**的环节，
形成可持续更新的「环节 → 产品 → 公司 → 上市状态 → 国产化率」结构化清单。

## 整理方法（三步）

1. **分层**：按研报通行口径将 GPU 产业链切成 4 层 20+ 细分赛道
   （L0 上游制造根基 → L1 芯片与软件栈 → L2 整机与基础设施 → L3 应用需求方）。
2. **映射公司**：每个细分赛道填「海外主导者 / 上市公司（含代码）/ 未上市公司（含资本进度）」。
3. **打标**：给每个赛道标注国产化率（约值）、卡脖子等级（★1~5）、证据等级（A/B/C）。

## 维护约定

- 所有数字型国产化率均带**证据等级**：A=研报/官方有明确数字；B=行业常识估计，待核实；C=待补充。
- 未上市公司的状态字段写清资本进度（如「港股聆讯通过」「科创板IPO受理」「无公开融资」）。
- 每季度更新一次：先改 `data/companies.csv`，再同步生成文档；文档与 CSV 不一致时以 CSV 为准。

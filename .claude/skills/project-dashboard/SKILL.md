# 项目仪表盘（Project Dashboard）

把本项目研究成果生成**单文件可视化 HTML 仪表盘**：产业链地图、国产替代率地图、公司清单（可搜索/筛选）、前瞻情景与可证伪判断（可勾选跟踪）、宏观触发器与 FRED 行情图。自包含、无外部依赖、可离线打开、可直接分发。

## 何时使用

- 用户要求「可视化」「仪表盘」「生成 HTML」「大屏」等项目内容呈现需求
- 文档或 `data/companies.csv`、`data/market_data/` 大规模更新后刷新仪表盘

## 工作流

```bash
# 在 repo 根目录执行（默认输出 dashboard/index.html）
python3 .claude/skills/project-dashboard/scripts/build_dashboard.py --open
# 可选：--root 指定 repo 路径，--out 指定输出路径
```

生成后向用户报告：输出路径、文件大小、解析到的数据量（公司数/FRED 序列数/表格数）。解析量为 0 的部分 = 锚点失配，按「数据契约」排查。

## 数据契约（脚本按这些锚点解析，改文档标题会失配）

| 数据 | 锚点 |
|---|---|
| `data/companies.csv` | 14 列 CSV（唯一事实源），列名不变即可 |
| `data/market_data/*.csv` | FRED 导出格式 `observation_date,SERIES` |
| `data/market_data/MACRO_PANEL.md` | `## N. 名称（规则）— 🟢/⏳/🔴 状态` 分节 |
| 03 国产替代率地图 | 标题含「〇、半导体设备」「二、A 类」「三、B 类」「四、C 类」「五、跟踪清单」 |
| 06 因果链核验 | 「一、结论」（链环表）「五、性质 vs 时点分离表」「六、观察清单」；正文 `**综合判断：…**` |
| 07 前瞻情景 | 「一、先修正前提」（SDLLMTK 表）「### 情景一/二/三」「四、脆弱性排序」「五、前瞻时间表」「六、可证伪的前瞻判断」「八、监控仪表盘增补」 |

## 已知坑

- 文档标题改名 → 对应板块解析为空：先核对上表锚点，其次才是改脚本
- 表格单元格内出现**半角竖线**会截断列（现有文档无此用法，新增内容避免）
- FRED 单个 CSV 缺失/为空时跳过该序列，不致整体失败
- 「可证伪判断」的成立/失效勾选状态按**判断文本前 40 字**存浏览器 localStorage——改判断文字会丢历史勾选；换设备不跟随
- 输出为生成物：默认建议 `dashboard/` 加入 `.gitignore`（可随时重新生成）；若要发布到 GitHub Pages 再自行取消忽略

## 特性

- 输出为纯静态单文件，双击以 `file://` 直接打开（无 fetch、无 CDN、无 CORS 依赖），可直接分发
- 改 `assets/template.html` 后需**重跑生成器**才生效（模板不会热更新到已生成文件）

# 市场观点核验（Market View Verification）

对任何市场观点做**数据驱动**的真伪判定。核心原则：

> 事实核验（对错）与论证评估（是否以偏概全）与结论判定（性质之变还是时点之变）必须分层，
> 不能因为论据属实就接受结论，也不能因为结论激进就否定论据。

## 工作流程（五步）

### 第一步：提取并编号论据
读完全文后把观点拆成**可验证的单条论据**（通常 5-15 条），分三类：
- **事实型**：含具体数字（"保证金债务 1.5 万亿"）→ 直接核数据
- **解读型**：因果判断（"这意味着泡沫在破裂"）→ 查证据是否支持唯一解读
- **预测型**：未来判断（"明年跌 21%"）→ 查该机构原口径与触发条件，是否被断章

### 第二步：跑数据脚本核验事实层

```bash
# 宏观触发器面板（FRED 免 key，含利率/实际利率/信用利差/VIX/指数回撤/油价/加息路径）
python3 scripts/fetch_fred.py --outdir <项目>/data/market_data

# 行情快照（默认：A股算力双链 + 美股芯片vs超大规模厂商，可自定义）
python3 scripts/fetch_quotes.py --mode both --outdir <项目>/data/market_data
```

脚本输出 markdown 面板，触发器状态（🟢正常/⏳测试中/🔴已触发）见 `references/triggers.md`。

### 第三步：WebSearch 补 API 拿不到的数据
API 覆盖不了的要搜：机构原始报告口径、公司财报 capex/FCF、债券发行量、FINRA 保证金债务（月度、滞后约 6 周）。
**搜索时必须找该论据的反方证据**（如引用空头报告时要找它没引用的部分——例如"凯投宏观预计先涨 8% 再跌 21%"）。

### 第四步：论证层评估
逐条检查四个常见漏洞：
1. **选择性引用**：只给吓人指标（CAPE）不给温和指标（forward P/E）
2. **指标误用**：盘中触及 vs "果断突破"；单月回落 vs 趋势拐点
3. **概念混淆**：安全/治理信号（如"放慢 AI 开发"呼吁）≠ 需求转弱数据
4. **时点 vs 性质**：脆弱性指标（杠杆、估值）说明"点火即爆"，不说明"何时点火"

### 第五步：分层结论 + 报告
按模板输出（完整模板见文末），核心是**性质/时点分离表**：

| 命题 | 成立？ |
|---|---|
| "XX 发生结构性变化"（性质之变） | 看融资结构/定价范式/约束条件是否切换 |
| "XX 即将终结"（时点之变） | 看终结信号：信用利差、VIX、破位、龙头指引下修——**四者全缺则时点未到** |

## 证据分级（沿用项目规范）

- **A级**：官方一手数据（FRED/BLS/交易所/公司 IR/招股书原文）
- **B级**：机构转述、媒体汇总（需标注"待复核"）
- **C级**：未核验/估算

## 已知坑（2026-09 实测）

| 坑 | 现象 | 替代方案 |
|---|---|---|
| stooq.com | JS challenge 拦截 curl | 放弃，用 FRED/新浪 |
| Yahoo query1 | 频繁 429 Too Many Requests | 用新浪美股 |
| 东财 push2his | 连接被重置（带 ut 参数也偶发） | A股用腾讯 qt.gtimg.cn |
| 新浪美股 | 403 无 Referer | 必须带 `Referer: https://finance.sina.com.cn` |
| 新浪美股字段 | 位置随批次漂移、含空字段（`float('')` 会炸掉整行）；52 周高低/市值不可用固定索引 | 只信锚点 f[0]名称/f[1]现价/f[2]涨跌%/f[3]时间；市值用数值扫描定位（脚本已内置） |
| 腾讯 A 股 | GBK 编码 | decode('gbk') |
| FRED 滞后 | 序列约滞后 2-4 个交易日 | 最新几日行情用新浪快照补 |
| FINRA 保证金债务 | 月度 + 滞后约 6 周 | 只能 WebSearch（advisorperspectives 月更解读可靠） |

## 报告模板

```markdown
# 观点核验：《<文章标题>》（日期）
## 一、论据逐条核验（表：# / 论据 / ✅⚠️❌ / 说明 / 信源链接）
## 二、数据面板（两个脚本的输出）
## 三、论证层问题（选择性引用/指标误用/概念混淆）
## 四、双面证据（空头已证实的 / 多头的硬数据反证）
## 五、性质 vs 时点分离表（最终判定）
## 六、观察清单（每条带验证日期与失效条件，如"Brent<85 则假设作废"）
## 七、组合/项目含义
## 信源清单（全链接）
```

归档约定：报告存入项目目录（如 `05_观点核验_<主题>_<日期>.md`），原始 CSV 存 `data/market_data/`，后续轮次以"第 N 轮"追加而非覆盖，保留判断演化轨迹。
